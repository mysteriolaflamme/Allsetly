# Allsetly - AI-Powered Visual Commerce Engine
Founder: EPHISCOWELL
Website: https://allsetly.com

## About
Allsetly is transforming the African informal economy by turning WhatsApp photos and voice notes into secure e-commerce listings using Meta's AI models (Muse Spark, SAM 3.1).

## Tech Stack
- Python
- Meta Model API
- Baseten (for Muse Spark Open inference)
