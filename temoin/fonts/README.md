# Bundled fonts

`DejaVuSans.ttf` (DejaVu Sans 2.37, from the official release at
https://github.com/dejavu-fonts/dejavu-fonts/releases/tag/version_2_37)
renders the evidence board text with full French accents on every platform.

DejaVu fonts are distributed under the Bitstream Vera license with DejaVu
changes in the public domain (see https://dejavu-fonts.github.io/License.html):
